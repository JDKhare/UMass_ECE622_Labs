\section*{Overview}
This report documents reachability analysis for hybrid models using \textbf{PHAVerLite}, following Lab~3. Hybrid systems combine continuous flows per location with discrete jumps; PHAVerLite uses a piecewise over-approximation of the dynamics so that unreachability results are sound for the concrete model, while reachability of a target in the abstraction does not imply reachability in the original system \citep{Frehse2008STTT}.

The workflow in each part was: (1) obtain or build a \texttt{.pha} model, (2) set partition constraint \texttt{pc} and location invariants to bound the search, (3) compute reachable sets and/or run \texttt{is\_reachable} checks, and (4) relate plots and tool output to the lab questions.
